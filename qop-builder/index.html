Validation & Rule Reference — mirrors Automated_QOP_Builder.xlsm VBA stages

🔴 [13] Programming Bulletin Conflicts → Col U mild red
Each row passes 4 gates IN ORDER before flagging:
1. Date overlap — outage start–end intersects PB window (PB times converted from NSW to site-local, DST-aware in VBA)
2. State gate — PB State is ALL / NATIONAL / contains the site's state
3. Network gate — PB Network (e.g. SBS, ABC, 7/SEVEN) must appear in the row's Service list. Multi-network "SBS/NITV" splits on / and ,
4. Service gate — PB Service_Name = ALL applies by DTV/Radio type; named services match by containment; generic labels (LOCAL RADIO, ABC NEWS ON RADIO) and group tokens (7 PGM, 9 PGM) handled
🟢 [14] Recommissioning → Cols V–W soft green
Site matched by number or name against the Recomm Schedule. If the outage date falls within ±30 days of the APT Due Date:
• Col V — "Recommissioning [service] due [date] (±Nd from outage)"
• Col W — "COMBINE: schedule recommissioning test during this outage" (or "REVIEW" if service differs, "already completed" if status is complete)
🟠 [15] Public Holiday → Col X light orange
Start date checked against the holiday calendar for the District's state (District → State mapping: Sydney→NSW, North Queensland→QLD, etc). 8 state calendars built in for 2026 + 2027.
🔵 [16] Antenna Testing → Col Y mild blue
Site's earliest Next Due in the Antenna SNP data checked against the schedule year:
• Overdue → "ANTENNA TEST OVERDUE … add antenna test to this outage"
• Due this year → "consider combining"
VBA also generates/splits antenna test rows (Stage 6) with standard description, code 41, OFF/OFF.
🟡 [17] Timing + Outage Window (Stage 9) → Cols K/L/AD mild yellow
Faithful port of the Excel Stage9_OutageWindowValidation. For each service on the row: extract customer (ABC/SBS/SCA/WIN/Seven/Ten) + service type, then match against the approved Outage Windows table by customer × service type × population × day type (weekday/weekend) × service class × time overlap (midnight-aware).
• Any service Outside a window → Timing = Outside, "Exception approval required" + AD note
• Else any Primary overlap → Primary
• Else Secondary → Secondary (>15k population adds "by exception – approval req.")
• WIN/Seven "Allowed" portions count as Primary; "Limited" only if OFF and outage ≤5 min
• Not service-impacting (AI = NIL and SS = NOP) → Timing left blank
Editing a row's Start Date re-runs Stage 9. Timing changes from the previous QOP are highlighted amber.
🔵 [18] Service Name Validation → Col AE blue / yellow
Each service on the row (split on ; and ,) is compared both ways against the THSS service list for that site (Remedy Source of Truth):
• Service on the row but not in THSS → hard flag "NOT IN THSS for site N" (blue)
• Service in THSS but missing from the row → minor warning "MISSING (warn)" (yellow)
• Site not in the THSS map → "verify manually"
The Service column keeps the row's own service; the full THSS list stays in Remedy Source of Truth for comparison only.
🟠 Description of Work Rules (Stages 6+8) mild orange
Antenna rows (code 41 / "Antenna Test"): description standardised to "N Yearly Antenna Test [TYPE]" from the SNP record matching the site + antenna type (DTV / FM / AM derived from services). Activity → 41, AI/SS → OFF/OFF.
SPM rows (code 40 / "SPM"): sites with AM (Local Radio) → "SPM - Audio & AM Noise Measurements" (intrusive); FM/DTV-only → "SPM - AFSR. Non intrusive works".
Cells changed by any rule highlight mild orange — compare against the Original columns.
🔴 Mandatory Fields & New Sites light red
Missing Start Date, End Date, Description, Activity Number, Service, or Site Number → cell highlighted light red.
NEW_SITE rows (not in previous QOP) → identity columns highlighted, note written to SPM Completion Notes.
ℹ Run order matches the Excel: Import [1] → Shift Dates [2] → PB [3] → Holidays [4] → Recomm [5] → Antenna [6] → THSS [7] → Build QOP → checks [13]–[18] run per row → review colour-coded grid → ↻ Re-run Validations after edits → Export CSV.
