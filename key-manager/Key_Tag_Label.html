This is what the scanner reads — use the same key number your Key Manager tracks. Letters, numbers and hyphens only.

Key numbering schemes
  • Cyberkey — use the serial number, e.g. K120007CA
  • Unique keys — key part number + serial, e.g. 5AB434N2B8-494
  • Undefined keys — XXXX-AAAA-SSS-EE
  • XXXX = site number
  • AAAA = building
  • SSSS = cabinet
  • EE = sequence number
