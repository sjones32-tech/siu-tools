PSN IBC Coverage Survey — Field Procedure BAI SIU · TTN-001

Technical Training Note for obtaining repeatable PSN radio coverage measurements inside buildings using the Anritsu S412E LMR Master. Covers software preparation, map creation, instrument setup, walk-survey deployment, and result compilation.

Document Ref
XX–TTN–001
Authors
Phil Spencer · Murray Lynch
Classification
PROTECTED · BAI Internal
Equipment Required
💻
BAI laptop or suitable laptop with local admin access (LAPS). Required for easyMap Tools software installation.
📡
Anritsu S412E LMR Master — ensure battery is fully charged. Required options:
• Option 521 — P25 / P25 Phase 2 Analyser Measurements
• Option 522 — P25 / P25 Phase 2 Coverage Measurements (requires Options 31 and 521)
All BAI S412E units observed to date have these options already enabled.
📶
UHF whip antenna — FLEXI-BNC90-433 with BNC-to-N adaptor for the S412E RF In port.
RF Solutions FLEXI-BNC90-433 — Mouser Australia ↗
🎒
Carry strap for hands-free walking surveys.
📻
Handheld PSN radio (optional) — for voice tests if required alongside coverage measurements.
💾
USB thumb drive — FAT32 formatted, small capacity. Large capacity drives can cause problems with the S412E file browser.
Stage 1 — Prepare

1A — Obtain floor plan drawings

1
Contact the building manager, check online, or source from the site "For Construction" document package.
2
Create one drawing per floor for multi-storey buildings. Break up large floor plans into workable sections if the building is extensive.
Tip: Landscape orientation (wider than tall) makes better use of the S412E screen. Crop or rotate floor plans before converting.

1B — Install easyMap Tools (PC)

1
Download the Anritsu Software Tool Box (Full Installer):
Anritsu Software Tool Box — Anritsu Asia Pacific ↗
2
Secured laptop users: Copy the downloaded installer into your local admin folder (LAPS) and install using your local admin credentials — e.g. User: ./ladmin Password: [your LAPS password].
3
Run Anritsu Tool Box and select easyMAP Tools from the Applications list.

1C — Create the .map file in easyMap Tools

1
Open easyMap Tools and create a legacy indoor map with no GPS:
File → Open Image File (MAP)… → select your floor plan image → save changes.
2
Boundary GPS coordinates can be added if known, but are not mandatory for indoor surveys.
3
Copy the generated .map file to the root directory of a FAT32 USB thumb drive (not inside any folder).
Alternative: Use the Map Converter tab in this tool to create a compatible .map file directly from any floor plan JPG or PNG — no easyMap Tools install required.

1D — Load map onto the S412E

// Navigate to coverage mapping
Menu → P25 2 Analyzer
→ Measurement → P25p2 Coverage
→ P25p2 Coverage (press again)
→ Save/Recall Points/Map → Recall a Map
→ Select Map as file type → navigate to USB → select your .map file
If the file doesn't appear: Press Refresh Directories. If still not visible, eject and re-insert the USB, or reformat the drive as FAT32 and retry. Large capacity or exFAT/NTFS drives will not be recognised.

1E — Configure frequency and amplitude

1
Research the signal source — identify whether coverage is from an external site or in-building repeater. Note the control channel frequency (Channel 1) or initiate a continuous transmit test for a specific channel.
2
Set receive frequency to the base station transmit frequency:
Frequency → Rx Freq
3
Connect whip antenna to the RF In port. Configure amplitude:
Amplitude → Rx Power Offset (enter attenuation if used) → Auto Rx Range: ON

1F — Configure measurement timing

1
Navigate to timing setup:
Measurement → P25p2 Coverage → Point Distance/Time Setup
2
Set Repeat Type: Time and configure the Repeat Time to match your walking speed.
Example: if it takes 10 seconds to walk between locations, 300 ms is a suitable interval.
⚠ For indoor surveys there is no GPS — measurement points are placed by manual screen tap, not distance-based triggering. Always use Time mode for indoor work.
Stage 2 — Deployment (Walk Survey)

Walk-path method (recommended for corridors)

1
Press the screen at your current location on the floor plan map (indicated by the black crosshair).
2
Press Start Data Collection. Data points will begin plotting at the configured time interval.
3
Walk to your next destination in a straight line.
4
Upon arrival, tap your new location on the map. Data points will populate along the walked path. Press Stop Data Collection.
5
Repeat for each segment, changing axis/direction as needed.
Example timing: A vertical corridor segment taking 10 seconds to walk at 300 ms capture rate will generate approximately 33 data points. A 3-second horizontal segment generates approximately 10 points.

Stationary point method (for spot checks)

1
Touch the map at your exact location.
2
Press Start Data Collection, wait for at least 1 data point to register, then press Stop.
3
Move to the next location and repeat.
Plot point colours change automatically to reflect current RSSI levels — green (Excellent) through to dark red (Poor).
Stage 3 — Save Results
1
Insert USB thumb drive. Touch the floppy disk icon at the top of the screen.
2
Press Change Save Location and select the USB drive before saving.
3
Enter a filename, then save two file types using the dropdown:
JPEG
Screen capture of the coverage map with colour-coded RSSI overlay. Used in reports and for visual presentation.
Mapping Tab Delimited (.mtd)
Raw measurement data with point coordinates, RSSI, BER, ModFid, and timestamps. Used for analysis and report generation.
Map grid reference: The S412E map display area is 640 × 420 pixels. The X/Y coordinates in the Tab Delimited file correspond directly to pixel positions within this grid, and can be cross-referenced to the original floor plan map.
Stage 4 — Compile Results
1
Add the saved JPEG coverage screenshots to the coverage testing report document.
2
Import the .mtd Tab Delimited file into the Report Generator tab of this tool to automatically produce an annotated map and PDF report.
3
Cross-reference data points to the floor plan grid using the 640×420 coordinate system if manual analysis is required.
This tool automates Step 2: Upload the .mtd file + JPEG to the Report Generator tab → generates analysis, annotated map overlay, and a print-ready PDF report in under a minute.
Background — S412E Measurement Types
RSSI
Received Signal Strength Indication. Determines RF signal power at each location to identify coverage gaps and dead zones. Primary metric for coverage surveys.
BER / Modulation Fidelity
Bit Error Rate and ModFid measure the quality of the received digital signal for P25/DMR/NXDN systems. Validates reliable communication even at low signal levels.
SINAD
Signal-to-Noise and Distortion ratio. Used for analogue NBFM systems to assess voice quality. Not applicable for P25 digital surveys.
OBW / Emission Mask
Occupied Bandwidth and Emission Mask spectrum analysis. Verifies transmission compliance with regulatory masks and absence of adjacent channel interference.

How to Use This Tool

Preparing your floor plan image

1
Get a floor plan image. Source it from the building manager, Google Maps screenshot, a scanned document, or draw your own. Any JPG or PNG works.
2
Resize to the S412E native grid. The S412E map display area is 640 × 420 px — this is the optimal image size per Anritsu documentation. Images up to 1280 × 840 px (2×) are fine and give slightly sharper rendering; anything over ~2 MB will load slowly on the instrument. Use Windows Paint or an online resizer to crop/resize before converting.
3
Save as JPG. The S412E's easyMap format natively stores JPEG data. PNG files will work too, but JPG is recommended for smaller file size.
Tip: Landscape orientation (wider than tall) makes better use of the S412E's screen real estate. If your floor plan is portrait, rotate or crop it before converting.

Indoor vs Outdoor mode

🏢
Indoor mode — GPS coordinates are set to 0.00,0.00. The S412E will not attempt to use GPS to position the cursor. You manually tap the screen to place your position as you walk. This is correct for PSN in-building coverage surveys.
🌏
Outdoor mode — You provide two GPS calibration anchor points (e.g. top-left and bottom-right corners of the image). The S412E uses these to translate your live GPS position into a pixel location on the map image. Use this for satellite/aerial imagery of outdoor sites.
⚠ For outdoor GPS mapping to work correctly, the two reference point coordinates must match the exact real-world locations visible in your image at those pixel positions. Inaccurate calibration will show the cursor offset from your actual position.

Loading the .map file onto the S412E

1
Format a USB stick as FAT32 (not exFAT or NTFS — the S412E will not see drives in other formats).
2
Copy the .map file to the root of the drive — not inside any folder.
3
On the S412E, press Measurements (bottom bar) → Over-the-Air → Mapping → press Mapping again to open the Coverage Mapping menu.
4
Press Save/Recall Points/Map → Recall a Map. Navigate to the USB drive and select your file.
5
The floor plan will load and display on screen. Set your frequency, Rx Pattern, and Repeat Time, then press Start Data Collection and begin your walk survey.
If the file doesn't appear: Press Refresh Directories in the recall menu. If still not visible, re-seat the USB drive, or reformat to FAT32 and try again.
Anritsu .map File Format — Reverse Engineered

The .map file format used by easyMap Tools and the Anritsu S412E LMR Master is a simple binary+text composite. It consists of a standard JPEG image with a small text footer appended directly after the JPEG end-of-image marker.

📄 .map file structure (byte layout)
// ─── Section 1: JPEG image data ───────────────────────
Bytes 0 … N-2 Standard JPEG binary (SOI to EOI)
Byte N-1, N 0xFF 0xD9 (JPEG End-Of-Image marker)

// ─── Section 2: Text footer (appended immediately after EOI) ───
<JPG>
lat1,lon1 // Reference point 1 (top-left GPS anchor)
lat2,lon2 // Reference point 2 (bottom-right GPS anchor)
<\JPG> // Note: backslash, not forward slash
FieldValue (indoor)Value (outdoor GPS)Notes
Section 1Raw JPEG binary dataStandard JFIF/Exif JPEG
EOI Marker0xFF 0xD9Standard JPEG terminator
Opening tag<JPG>Immediately after 0xD9
Coord pair 10.00,0.00-33.8688,151.2093Lat,Lon of top-left anchor
Coord pair 20.00,0.00-33.8695,151.2101Lat,Lon of bottom-right anchor
Closing tag<\JPG>Backslash (not forward slash)
Indoor surveys: Both coordinate pairs are 0.00,0.00. The S412E detects this and disables GPS-based cursor positioning, switching to manual touchscreen tap mode.
PNG images: The S412E can load PNG data in the .map container — the tool appends the same text footer regardless of image format. The instrument reads the raw bytes and decodes them as an image.
The .azm format is a newer Anritsu format used by current versions of easyMap Tools. It supports pan-and-zoom. This tool generates the legacy .map format (single panel, compatible with all S412E firmware versions).
